# Inventory Management System

A desktop-based Inventory Management System built with Python and PySide6. This project is designed to help manage inventory records through a graphical user interface.

## Features

- Graphical user interface built with PySide6
- Inventory and product management
- Database integration
- Easy-to-use desktop application

## Technologies Used

- **Python** — application logic
- **PySide6** — graphical user interface
- **SQL** — database-related files

## Project Structure

```text
Inventory-management/
├── main.py
├── main_window.py
├── main_window.ui
├── database.py
├── Db IM.sql
└── README.md
```

## Requirements

- Python 3.10 or later
- PySide6
- Any additional dependencies required by the project

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your GitHub username and repository name.

### 2. Open the project folder

```bash
cd Inventory-management
```

### 3. Install PySide6

```bash
python -m pip install PySide6
```

### 4. Run the application

```bash
python main.py
```

## Database

The project includes `database.py` and `Db IM.sql` for database-related functionality. Review the database configuration and setup instructions before running the application.
